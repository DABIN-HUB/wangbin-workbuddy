# 独立验收案例｜Q05 V2 冻结

来源：Q01 T00 附件19 §18.7–18.9（行1475–1527）、§30–33。以下每例使用**独立虚构** `source.xlsx` 与 `report.docx`（未特别说明时相同主体“青禾公司”、币种 CNY、实际、未税、所述期间 2026-06、无其它规则），在干净目录由测试程序构造 XLSX 真实数值单元格和 DOCX 真实正文段落/普通表格，再运行产品，重开五表检查实际内容/数值和原件 hash 不变；不得把被测实现输出复制成预期。默认不提供舍入规则；需精确比较的案例显式注明。每例应独立启动，不共享其它例隐含状态。所有期望的差额为报告换算后－来源，未计算不是0。若某例为用户明确声明的规则，测试应将声明作为 `context` 传入并核查其证据。

## 验收执行及门禁
每例必须断言**五个工作表名称**、必需明细列/待确认/未覆盖内容、可重开且非空、报告与源件哈希不变、无跨目录副作用。标明实际运行命令、退出码、失败差异，保留独立预期与输入构造依据；不允许只检查文件存在或只凭口头总结。开发自测≠独立 QA；从不可覆盖候选 ZIP 干净解压再跑核心 A–D、REP-A05–A16、错误与多轮流程，核实源码提交/包/依赖和推荐问法；未跑均写 NOT_TESTED。许可、平台安装/评测/审核/上架、相似性人工审查不因本地案例通过自动 PASS；无授权不上传/发布。
