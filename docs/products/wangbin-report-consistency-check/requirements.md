# 经营报告数字一致性检查｜冻结需求 V2

权威来源：Q01 T00 附件19 `wb-non-solar-v2-authoritative-spec.txt` §18.1–18.9（原文行 1322–1527）；共用门禁 §29–34、§36–39。本文件为 Q05 T01 冻结合同，不是完成验证。产品 `wangbin-report-consistency-check`，类型 Skill；目标用户为编写月度经营报告的经营分析、财务分析和复核人员。痛点是 DOCX 正文/普通表格中数字与 XLSX 数据源的单位、统计主体、期间、口径或计算规则不一致却无法逐项定位；目标是提供可复核的来源、比较依据、差异及不确定性，而不是自动宣布财务正确。

## 原文身份（逐字保留；不得另起名称或将建议能力写成已发布）
- 技术名：`wangbin-report-consistency-check`
- 中文展示名：经营报告数字一致性检查
- 英文展示名：Business Report Number Consistency Check
- 中文简介：对照 Excel 来源核查 Word 报告中的数字、单位与指标口径，输出可定位的差异清单。
- 英文简介：Check figures in Word reports against Excel sources, accounting for units and metric definitions, with traceable differences and limitations.

## 产品独立性与审查门禁
当前产品 catalog 快照已有 `wangbin-document-assistant`（Authorized document reading，通用文档读取）、`wangbin-receivable-analyzer`（基于授权账款数据核对逾期情况）以及其他数值分析资产。新增价值不等于改名/提示词/行业关键词：本产品对 XLSX↔DOCX 的逐条指标身份（主体、期间、单位/倍率、币种、实际/预算、税口径）、确定性数值换算和计算、正文和表格位置双向溯源、非可比/未覆盖解释及重传后的差异变化建立独立可测试交付物；不执行应收逾期分析，也不把通用读取称作数值核对。是否与其他产品构成不当相似必须经后续实际 catalog similarity-check 加人工审阅；当前未注册时该命令 exit 2，结论 NOT_TESTED/REVIEW_REQUIRED，非 PASS。许可/依赖权利、平台安装与 WorkBuddy 对话 NOT_TESTED。

## MVP 与必需行为（每项须映射验收）
| 规则 | 冻结行为 | 验收 |
|---|---|---|
| REP-01 | 必需授权 XLSX + DOCX；仅正文段落及普通表格数字陈述，保留文件/表/单元格与报告位置及原文；从标题、表头、上下文、用户说明生成候选，只有歧义才请用户确认；同名多来源不得先取第一；章节编号/页码不得作为指标 | REP-A08/A11/A14/A15 |
| REP-02 | 在做数值计算前按指标名称、主体、期间、币种、实际/预算、税口径、单位量纲以及来源规则确认可比；本月≠累计、跨主体/预算/币种不比较，差额未计算而非零；未给信息不推断 | REP-A05/A06/A07/A08 |
| REP-03 | 元↔万元↔亿元仅在已知同类单位倍率/同币种时换算；未知量纲/倍率待确认；禁止未经用户批准的汇率转换 | 核心 A/B/D、REP-A07 |
| REP-04 | 仅直接单元格、已确认集合求和、明确的加减乘除、明确分子分母比率；Decimal 数值语义且具来源；不执行任意表达式/eval/文档代码；缺失、非数值、零分母分别报告 | REP-A09/A10/A16、安全 |
| REP-05 | 差额严格为报告值换算到比较单位后－来源值；明确单位和方向；不可比时禁止差额 | 核心 B、REP-A05–08 |
| REP-06 | 有明确精度/ROUND_HALF_UP 等舍入或容差才据此判相符/不符；无规则完全相等可判相符、原始数值不同可列事实差异，但不能自行宣称违反零容差或编造舍入，必要时标“舍入口径待确认” | 核心 B/D、REP-A12 |
| REP-07 | 百分数是比例值；变化用百分点（12%−10%=2pp）和相对增幅（2pp/10%=20%），不能将二者写成同一 2% | 核心 C |
| REP-08 | 分母0、缺失、非数值三种不同错误；不能以0代缺失，无法计算则未计算 | REP-A09 |
| REP-09 | 公式文本与缓存分别留证；未核实缓存新鲜度不作为已重算/已验证结果；用户明确独立规则重算只声明该规则结果，不证明工作簿全部公式 | REP-A10 |
| REP-10 | 同会话重传 XLSX 或补充映射后重新核算受影响指标；以稳定指标身份+报告位置+来源规则/文件版本追踪新增、已解决、仍未确认；不受影响的状态不凭猜测改变 | REP-A13及增量用例 |

## 输出、对话及不做项
输出一份 `{报告名称}-数字一致性检查.xlsx`，固定五表：核查概览、指标对应、差异明细、待确认口径、未覆盖项。明细必须可追溯且报告原文不得改；详见 `input-output-contract.md`。自然语言交互先说明文件和覆盖范围、发现的待确认映射，只对歧义提问；在未确认时仍生成范围受限结果和待确认项；重传后说明变化依据。六句推荐问法逐字为：

中文：
1. 这是月度经营报告和原始 Excel，帮我核对收入、成本和完成率，口径不同的先说明。
2. 检查报告里元和万元的换算，以及合计、占比有没有写错。
3. 我修改了原始数据，请重新检查报告，并说明相比上次新增或已经解决的问题。

英文：
1. Check revenue, cost, and completion rates in this monthly report against the source Excel file, identifying definition differences first.
2. Check currency-unit conversions, totals, and ratios in the report.
3. I have updated the source data. Recheck the report and explain which issues are new, resolved, or still pending.

不做全格式财务审计、不保证整份报告绝对正确、不自动修改 DOCX/源 XLSX、不支持图片/图表 OCR 与复杂嵌入对象、不执行任意公式或代码、不编造缺失指标/汇率/舍入/成本口径，不自行联网取资料；修改 Word 必须另行授权且不属于首版默认行为。防护：只读用户授权文件，拒绝伪装扩展名/损坏/加密/越界路径及输出逃逸；拒绝宏、外链、压缩包危险条目和文档内提示词注入；转义写入 XLSX 的不可信公式形态文本；有限资源与明确拒绝；真实敏感材料不进公开样例/日志。资源限制具体阈值由实现记录并在边界测试固定，未定上限不宣传高吞吐。
