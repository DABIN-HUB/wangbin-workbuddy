# 输入输出与状态契约｜Q05 V2 冻结

依据：Q01 T00 附件19 §18.3–18.6（行1354–1473）、§18.9、共用§31–33。产品 `wangbin-report-consistency-check`。此处定义逻辑契约；实现 CLI/WorkBuddy 参数名称由开发登记，但必须保持以下必选/可选语义，不能强迫用户先手工列出每个单元格。文件必须是用户授权的本地输入，输出写在用户授权的目录。

## 输入、提取和定位
| 入参 | 必需 | 契约 |
|---|---|---|
| `source_xlsx` | 是 | 至少一个有效 XLSX 数据源；标记文件名及版本/内容指纹、sheet、A1 单元格/已确认范围；不能只引述未定位的模型概括。若多个候选来源，保留全部且提问。 |
| `report_docx` | 是 | DOCX 正文段落及普通表格的可读文本；记录文件名/版本、段落序号或表格序号＋行列、原始引述；图片、图表、页眉脚、脚注、嵌入对象等未解析内容列未覆盖，绝不宣称检查完毕。 |
| `context` | 否 | 统计主体、期间、指标定义、税口径、计算说明、已确认映射、精度/舍入模式/容差、单位/币种，由文件标题、表头、附近文字及用户说明获取，分别记出处与确认状态；不凭模型猜测填成事实。 |
| `prior_run` | 否 | 同报告上一次核查的可追溯快照，用于重传变化对比；无旧快照只出本次，不能伪称“已解决”。 |
| `output_dir` | 是（执行落盘时） | 用户授权输出位置；拒绝输出逃逸及覆盖用户原件，文件名用安全化报告基名但保持报告名称可追溯。 |

指标记录字段：`metric_id`（稳定唯一标识，映射变化保留追溯）、名称、主体、期间（本月/累计/日期区间）、单位及倍率、币种、实际/预算、税口径及其它必要定义、来源文件/工作表/单元格或明确确认的计算规则、报告文件及位置、报告原始表达、可比状态、精度/舍入依据。信息未知时记录 UNKNOWN 与缺项，不能把名称相同当完整身份；显示位置不合并互相矛盾的多处陈述。候选映射以可观察的标题/表头/上下文及已确认规则建立，多个合理来源均为 AMBIGUOUS_MAPPING，不取首个；歧义项应要求针对性确认，而明确项继续核查。页码、日期章节编号不应无根据进入指标集合。

## 判定与算术
1. 解析值为十进制数及单位/币种/百分号；缺失 `MISSING`、非数值 `NON_NUMERIC` 和数值零 `ZERO` 必须区分。来源公式对象同时记录公式文本与缓存值/缓存可信状态；缓存存在但新鲜度未知=`UNVERIFIED_FORMULA_CACHE`。禁止把缓存当重新计算的验证证据；仅当有用户确认的独立计算规则且各依赖有效时可独立计算，并标为`INDEPENDENT_RULE_RESULT`。
2. 比较先于计算：主体、统计期间、实际/预算、税口径、币种、单位量纲、其它定义均一致或有明确授权映射，才进入数值比对。不可比=`NOT_COMPARABLE`，不确定=`PENDING_CONFIRMATION`，差额与比较用值为 blank/`未计算` 而非0；跨币种无授权转换一律不做 FX。仅使用已知倍率：元×1、万元×10000、亿元×100000000（先同币种）；百分数 10% 数值比率为0.10，百分比差以百分点表示，relative change 需确认基数非0。未知单位不得猜。
3. 白名单计算 `direct(cell)`、`sum(confirmed_cell_set)`、`add/subtract/multiply/divide(explicit_operands)`、`ratio(explicit_numerator,explicit_denominator)`；每个操作数保留来源和单位，除0=`ZERO_DENOMINATOR`，缺数=`MISSING_OPERAND`，非数值=`NON_NUMERIC_OPERAND`。只执行结构化确认规则，不允许 `eval`、`exec`、公式字符串任意解释、输入文档内宏/外链。含单位不兼容运算不得返回貌似正确值。
4. 统一比较单位先转换报告与来源，再得 `delta = normalized_report - normalized_source`；每条输出明确换算步骤与差额单位/方向。直接引用、合计、比例都遵守此方向。精度与舍入/容差只有明确给出才用于一致性判断；明确精确比较且不等=`MISMATCH`，完全相等=`MATCH`；未有规则而原始不等=`RAW_DIFFERENCE_ROUNDING_PENDING`（描述事实而非违规），未知规则不得用自造零容差。明确 ROUND_HALF_UP 按显示位数舍入来源再比较报告显示数，并留存未舍入的来源。可单独展示原始差额，不能误把因明确舍入而相符的值写成违规。
5. 来源值及可信范围必须说明是直接数值、经确认规则独立算得还是仅未经验证公式缓存；缓存不新鲜/未知时不得出现已核验一致。映射确认后或新 XLSX 重传只重算受影响项，比较旧新基于相同报告版本和可追溯 identity/位置/规则；`NEW`、`RESOLVED`、`STILL_OPEN`、`STILL_PENDING` 及 `CHANGED_CONTEXT/UNCOMPARABLE_TO_PRIOR` 应反映真实可比性，不把失踪/重新映射误当解决。

## 输出 XLSX（五表名称逐字）
文件 `{报告名称}-数字一致性检查.xlsx`，UTF-8 可见文本、可在 Excel/openpyxl 重开；数值字段保持数值精度或标明显示精度，所有不可算数字单元格留空而非0。每表均可引用输入版本、运行批次与支持范围。

| 表 | 最低列/内容 |
|---|---|
| 核查概览 | 来源/报告文件及版本，核查范围与未覆盖范围、每类结果计数（只统计实际扫描），规则/待确认汇总、对上次变化说明、已核实/未核实声明。 |
| 指标对应 | metric_id、指标完整身份各分量、报告文件/位置/原文、来源文件/表/单元格或规则、候选及确认证据、状态；多候选逐项保留。 |
| 差异明细 | `metric_id`、指标、主体、期间、单位、币种、口径、来源文件／工作表／单元格、来源值与来源可信范围、报告位置、报告值、换算过程、规则及精度、比较结果、差额与差额单位、解释、建议和限制；包括明确差异与原始差异待舍入确认，必要时报告多位置冲突；引用应能定位到证据。 |
| 待确认口径 | 指标/报告位置、缺失的主体/期间/实际预算/币种/税/单位/舍入等，候选来源及出处、待用户回答的问题、阻断计算的原因、状态与未计算差额。 |
| 未覆盖项 | 文件、区域/位置、未覆盖类型（图片/图表/嵌入对象或解析限制）、原因、影响、建议人工复核；不把未扫描项当无问题。 |

对用户回复：先给覆盖/未覆盖、核对摘要、差异方向及待确认问题、下载产物和来源限制；若用户要求改 Word，说明未经独立授权不改。六条原文推荐问法在 `requirements.md` 逐字冻结并在真正对话与多轮重传中分别测试。

## AUDIT-R1 Q05 补充的可执行输入→事实→输出契约（REP-F01–F06）
本节补充原 V2 §18.3–18.6，不改变上述必选文件、五表和非审计边界。`context` 里的 `mappings` 必须记录用户确认的指标名称、来源 `sheet!A1` 或明确计算规则、报告位置/适用范围、主体/期间/单位/币种/税/实际预算已知字段及确认出处；未给字段保持 UNKNOWN，不借 `exact=true` 填补未知身份。只要某项已给明确来源就不能再因固定关键词表漏读。每个正式输出记录输入 SHA/版本、同次运行标识和覆盖范围；JSON 快照是现有实现辅助证据，五表 XLSX 才是 V2 必交付物，不能以 JSON 代替。

1. **来源可信度优先于数值**：来源字段至少 `source_file/hash/sheet/cell`, `raw_value`, `number_format`, `header_unit`, `unit_basis`, `formula_text`（公式格保留原文）, `cached_value`（有则留存）, `cache_freshness_evidence`（未知必须 UNKNOWN）, `provenance`, `source_rule`。读取公式与读取缓存需保留两种视图并关联同一坐标；公式格即使缓存恰好是报告值，也输出 `UNVERIFIED_FORMULA_CACHE`、明确待验证原因、来源位置及空数值比较/差额；绝不洗成 `DIRECT_CELLS` 或 `MATCH`。没有缓存也不是0。有版本和单元格绑定的可靠独立核算证据才可能改变该来源可信状态；由用户给独立白名单规则时，每个输入操作数都须通过相同检查，标 `INDEPENDENT_RULE_RESULT` 并把原公式留在溯源中，不能把该计算称为原式验证。合计、比率、变化、直接引用统一执行此检查，失败的操作数阻断整项已核实结论，同时允许其他独立指标继续核验。
2. **百分数证据及身份**：保存 XLSX 原值/格式/表头原文及各自尺度证据、规范化无量纲比例；若格式为百分比且原值0.1，显示10%，不再据 `(%)` 重复乘100。若普通数值格式且表头明确单位 `%`，原值10代表10%即比例0.10；明确 `10%` 文本也按比例0.10。无单位0.1或格式与表头含义冲突时 `PENDING_CONFIRMATION`（可具体指出单位歧义），不可按数值大小猜；未知比例不得进入变化计算。保存 `prior`, `current`, `change_pp = (current-prior)×100`, `relative_change = (current-prior)/prior`（若 prior=0 则空/未定义，change_pp 若有明确两值仍可算）；结果展示“+2个百分点；相对增幅+20%”而非“+2%”。增长方向与百分点的符号均取本期−上期；报告声称下降或反向数字须用真实数值比对，不只凭词匹配。不同期间角色可以比较变化，其他身份须先一致/明示规则；来源是收入时不能只看两个数就映射完成率。
3. **普通 Word 表格**：将 `表格N!RrCc`（从1开始）作为每个格的精确位置；“指标｜数值”的行输出标签格与数值格的成对坐标，“指标｜本月｜累计”分别绑定第2、3列表头给各行定义期间。表头单位（例如 `收入(万元)` 或 `本月(万元)`）作用在其列或明确的行标签范围，冲突则待确认而非静默覆盖；相同指标不同表/行/期间均保留各自报告位置及原文。同单位 `收入|0元` 对比来源0元是有证据 `MATCH`, delta=0元；`收入|空` 是 MISSING、待确认/未计算，不得当0也不得计为“没有可核指标”。真正解析不了的普通表格行在 `未覆盖项` 标明表格行列及原因；不允许仅有泛化未覆盖项。
4. **动态指标及多路径**：候选集是报告正文/普通表格、XLSX 表头/上下文和已确认 `mappings` 的有证据交集，不是硬编码词表；净利润已映射且报告给128万元、源1280000元同身份同币种 → `MATCH`, delta 0元；若只有无关章节号3.2或孤立日期，即使有数也不是指标。计算规则缺失的派生指标应列具体缺口，不能套猜净利润=收入−成本。同一 DOCX 中收入128万元、成本50万元、完成率10%→12%应分别出结果，不能用整份 `len(items)==2` 触发变化路径；原报告中另有冲突表述，则新增独立结果与冲突解释。
5. **正式五表交叉一致**：`指标对应` 含每个可见报告位置、匹配/候选和确认证据；`差异明细` 含数值可比项的来源原值与可信度、公式原文/缓存可信性或可通过源引用查得的等价字段、规范值与换算、差额单位与方向；无法计算的指标也不得消失，应在对应/待确认中出现并在明细呈现空比较值/空差额或可定位引用。`核查概览` 统计实际记录而非仅正常完成分支；`待确认口径` 给所缺证据与可回答问题；`未覆盖项` 标具体未解析表格位置。`UNVERIFIED_FORMULA_CACHE`、`AMBIGUOUS_MAPPING`、`PENDING_CONFIRMATION`、`MISSING_OPERAND`、`NOT_COMPARABLE` 不得含伪造0差额。输入源及报告文件不改动；追加补源或映射时按稳定指标+报告位置+来源规则/版本比较，仅受影响项重算，首次无前次快照时只标 FIRST_RUN。
6. **门禁分别记账**：旧 0.1.3 历史 44/44 PASS 与本轮新基线 8/17 PASS/9 FAIL 并列保留。旧开发测试 `test_spoofed_input_and_forbidden_output` 对字节 `not a ZIP` 错期望 `UNREADABLE_OR_ENCRYPTED`；按本合同应 `UNSUPPORTED_OR_SPOOFED`，须独立 QA 对照输入后由授权开发更正当前断言，不删除/跳过。旧 `release-check` exit1 的局部注册测试 12 passed/1 skipped，许可证缺失 `LICENSE_PASS BLOCKED`、相似性 `REVIEW_REQUIRED`、平台 parse/runtime/review `NOT_TESTED`；这些非该旧断言的同一根因，未核许可/平台不得更改状态凑 exit0。

## 错误/有限模式和安全
| 场景 | 强制结果 |
|---|---|
| 缺 XLSX/DOCX、伪造扩展名、损坏/加密、无法解析 | `INPUT_MISSING`/`UNSUPPORTED_OR_SPOOFED`/`UNREADABLE_OR_ENCRYPTED`；不给虚假 PASS。单个源失败不把值当0；能局部输出则概览标 `PARTIAL` 并列未覆盖。 |
| 来源多候选、口径不明/跨币种 | `AMBIGUOUS_MAPPING`/`PENDING_CONFIRMATION`/`NOT_COMPARABLE`；无伪差额。 |
| 缺失/非数值/零分母/缓存不可信/未知舍入 | 分别 `MISSING_OPERAND`、`NON_NUMERIC_OPERAND`、`ZERO_DENOMINATOR`、`UNVERIFIED_FORMULA_CACHE`、`RAW_DIFFERENCE_ROUNDING_PENDING`；前四种不可当已核实值。 |
| 输出目录无权限/路径越界或文件资源超限 | `OUTPUT_REJECTED`/`RESOURCE_LIMIT`；不读/写未授权目录，拒绝而不静默截断宣称完整；限制数值由开发固定并 QA 边界验证。 |
| 恶意文档内容、宏/外链、公式注入 | 当作数据或拒绝，永不执行；XLSX 写入字符串以安全文字写入，不能成为公式。保留源件字节不变。 |

禁止记录真实敏感材料为公开测试数据；开发与独立 QA 使用虚构文件并同时检查输出实际显示金额、差额方向和来源证据。外部平台字段和额度未验证，不能推断平台合格。
