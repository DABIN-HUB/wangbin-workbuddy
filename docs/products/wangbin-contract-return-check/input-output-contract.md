# Q03 输入输出与错误契约 — 安全重建副本

此文件仅冻结本地 MVP 接口语义，移除旧证据实物和本机路径。`original`（发出稿）与 `returned`（回传稿）由用户明确指定，不可借助名称/上传顺序/修改时间推断；独立 DOCX 同字节可合法比较。用户可选 `focus_topics`（付款/金额/交付/验收/服务范围/期限/其他）、`draft_message=false`、`contract_name=合同` 和获授权 `output_dir`。对话与参数相冲突先问，不沿用另一对文件的结果。CLI 可传独立授予的 `--authorized-root` 限定两输入和输出；这不是 WorkBuddy 平台接口已验证的声明。

## 读取与证据

每个单元须携带 role、source_name、source_sha256、kind (`body_paragraph | table_cell`)、从 1 起的正文序号或表号/行/列、逐字原文、上下文、支持状态；空值不当零。正文按顺序，普通表格按可见文字读取。只允许证据支持的 `ADD/DELETE/MODIFY/MOVE/NUMBER`，同号/同槽位/唯一剩余项仅是线索；确定配对依据唯一稳定标识及相容对象/动作、双方定位、排除竞争候选。条号与实质同改可分别记 `NUMBER` 和一次内容 `MODIFY`；纯相同文本调序只记 `MOVE`；无唯一表格标识或重复标题时保留所有合理候选但不生成确定 `MODIFY`。候选需有旧/新位置和原文、不确定理由与确认问题，不进入确定计数。单边确定增删可单独报告。主题与变化类型分开；来源原文保持否定词、金额、日期、付款天数、比例和条件。确定变化记录 change_id、双侧定位/原文/角色/哈希、type、topic、明确变化、对齐依据和确定度、中性可能影响、确认问题及覆盖边界。没有事实不得推断损失/动机/法律结论。

## 状态和限额

- `COMPLETE`：可比的正文/普通表格全部覆盖且无未决修订或重要未知；仅在全覆盖时说整份可比范围未发现差异。
- `PARTIAL`：有歧义对应或文本框、图片文字、扫描、嵌套表格等未支持载体；仍交付已确定项和未覆盖位置/影响，不把未知记作零。
- `NEEDS_INPUT: ROLE_AMBIGUOUS`：缺角色、冲突或两角色同一文件；`REVISION_STATE`：任何相关未解决插入/删除/移动等 Word 修订，须换明确接受修订后的比较副本，不能隐式接受。授权范围无法明确时停止并请求授权。
- `ERROR: INVALID_DOCX`：伪/坏/加密/不安全 OOXML；`LIMIT_EXCEEDED`：单份超过 10 MiB、2000 单元或 100000 字，或恶意 ZIP/XML；`IO_FAILURE`：不可读/写出失败；`UNSAFE_PATH`：用户原始指定的输入或输出路径任意现存组件为链接、junction/重解析点或越出已授根。本版不授权隐式重解析目标；检查前不打开目标或创建输出。新建目录前后复核链接和根；竞态无法安全控制就失败关闭。源文件 SHA-256 前后相等，不写源。

输出 XLSX 任何来自合同/用户名的字符串均按文字写，不将 `= + - @` 或前置空白/控制字符转换为公式；不执行宏或附件。输出唯一命名、不覆盖既有文件/源；失败时不产伪成功报告。

## 文件成果（必须实际生成、重新打开核查）

1. `{合同名称}-版本差异.xlsx` 恰好四张工作表：
   - `检查概览`：方向、角色与源名称/SHA、检查范围/状态、筛选与未展示主题、五类确定变化各计数与总唯一 ID、歧义/未覆盖数；筛选前后计数分开。
   - `逐项差异`：至少按 change_id、主题、原稿位置、回传稿位置、原文、新文、变化类型、明确变化、确定程度、可能影响、确认问题的列顺序，并具来源可追溯性。
   - `关键商务变化`：复用同一已确定 change_id 与双侧原文、位置、确认问题，不虚构新事实或重复计数。
   - `待确认与未覆盖`：候选原文/双侧定位、对齐不确定原因、修订/未支持载体、筛选外范围与待确认问题；候选不可算已确认。
2. `{合同名称}-商务变化说明.docx` 为真正可编辑 Word 文档，同样引用方向、范围、change_id、双方原文定位和待确认；`PARTIAL` 显著标识；仅在 `draft_message=true` 且有确定差异时据实生成礼貌草稿，绝不发送或代为接受。

`NEEDS_INPUT` / `ERROR` 可仅输出机器状态和解释而非两个文件；两个成功成果一致且源哈希不变。具体逐例冻结预期见 `acceptance-cases.md`；新虚构数据与 WorkBuddy 自然对话/平台均单独实测，不继承旧包历史 QA。
