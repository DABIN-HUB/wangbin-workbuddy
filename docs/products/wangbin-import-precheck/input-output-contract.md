# 输入输出契约｜数据导入前检查

依据：权威 V2 §06–14、§24、§32；规则见 `business-rules.md`，样例见 `acceptance-cases.md`。`0.1.0` 为拟用版本。

## 原始输入与必要条件
|资料|支持/必需条件|缺少或歧义时|
|---|---|---|
|待导入文件|必需；真实 CSV 或 XLSX；用户可指定工作表、表头、数据区；从原件只读读取|无文件 NEEDS_INPUT；伪格式、损坏、加密或无法安全解析 REJECTED；不能默选多表之一|
|目标模板或字段文字说明|完整目标导入预检必需；模板工作表或明确描述均可|缺失进入有限数据质量模式，目标未声明规则列入未检查，禁止“符合系统”|
|规则和字段对应|来自模板明示、用户文字或确认；必填、类型、长度、唯一组、允许值、成员、日期格式、允许转换|影响判定的冲突/一对多先确认；可处理其他独立项|
|参考表|仅执行对应关联规则必需；CSV/XLSX 本次快照，指定工作表/键|缺失对应规则 UNCHECKED，绝不判全体无效；重复键报告参考歧义|
|转换授权|缺省无；明确指向具体转换/映射和范围的用户指令|不执行修改、不生成“已全部修好”候选；分离合格部分须另有明确请求|

CSV 记录原始编码、分隔符、表头行、物理行号；编码/分隔符无法可靠判定则提出具体问题，不静默乱码处理。XLSX 记录 sheet、表头行、数据区、原始行号/列名/单元格坐标与原始单元格类型；识别重复/合并表头、公式列、多个可能表。CSV 文本原始字面值和 XLSX 单元格类型分别保存。标识符按文本语义原样保留（包括前导零、大小写、空格），数值单元格显示为前导零不等同文本编码。空单元格、字符串 `0`、数值 0、字面 `NULL`、`N/A` 分别保留，不自动互换。

内部字段规则每条均携 `rule_id, source_column, target_field, data_type, required, length_rule, unique_group, allowed_values, reference_file/sheet/key, date_format, allowed_transformations, rule_source, confirmation_state`；未知采用明确 UNKNOWN/未确认而非 false/零。字段对应另存依据与是否确认。业务行 row_id 由文件标识＋sheet/CSV区域＋物理行定位稳定组成，不以编码值当唯一行 ID；文件标识含可核验哈希、用途与解析范围。每个 finding 有 finding_id、row_id/业务对象、类别、原值、适用规则及来源、事实、原始坐标、确定状态、建议/待确认。内部 run 记录 product_id/version、request_id、源快照哈希、已/未确认映射、检查和未检查规则、统计口径、输出路径及校验、状态；本次重新运行与历史 run 分开。

## 输出文件与字段
主输出 `{原文件主题}-导入预检.xlsx`，重名增加 run/版本标记且不覆盖原输出，安全清理文件名同时保存源映射；至少五表、空数据也有表头：
|工作表|必须包含|
|---|---|
|检查概览|输入记录数、完全空白行数、无阻断记录数、有问题记录数、问题条数、重复组数、检查模式、已检查规则、未检查规则及统计范围/执行状态|
|字段映射|原始字段、目标字段、映射依据、确认状态、转换规则；待确认不显示成已生效|
|问题明细|finding_id、row_id、文件、工作表（CSV 可标无）、原始行号、字段/单元格、原值、规则编号、类别、说明、建议、是否阻断候选导入；一问题一行|
|变更记录|row_id、字段、原值、新值、转换规则、授权依据；无变更只有表头，不把建议写为已修改|
|未检查项|规则编号、缺少条件、影响范围、需补资料；未知目标规则说明检查范围，不能假设其内容|

满足 IMP-08 的映射、转换、授权及风险门槛时另输出 `{原文件主题}-候选导入.xlsx` 或对应 CSV，原始记录不会悄然删除；阻断项仍存在时不得声称全部可导。明确要求先输出合格部分时另输出 `{原文件主题}-隔离记录.xlsx`，候选仅含按已确认规则无阻断的记录，隔离包含其余记录及 row_id/原因；校验候选记录 ID 与隔离记录 ID 不交且并集等于本次全部输入记录 ID，注明未检查规则仍可能影响可导入性。没有明确分流授权不生成该隔离文件。对每个真实转换可从候选定位变更记录，并保持原件哈希不变。

XLSX 报告有筛选、必要冻结窗格、单位/长文本可读、长编号作为文本、空值/未比较值不写 0；不可信值以非执行文本写入 XLSX/CSV（防公式注入），不把宏或外链激活。输出实际可打开且汇总能追溯到行级证据；无可用渲染器时视觉检查 NOT_TESTED。文件权限范围只限授权输入与输出路径；拒绝路径穿越、符号链接逃逸及未授权读取。§09、§10、§13、§14.3–14.6、§32。

## 错误状态与用户措辞
COMPLETED＝已成功执行本次可检查范围并写出真实输出（可有业务问题）；PARTIAL＝仅部分安全可解析/规则可执行且结果明确未检查范围；NEEDS_INPUT＝必需文件或影响该判断的选择待补；REJECTED＝不支持/不安全/损坏输入，不对其作业务结论；FAILED＝执行或写出失败，不能提供虚构文件。状态不等于业务合格，任何 PARTIAL/NEEDS_INPUT 不能写“全部通过”。不可靠读取不应通过空结果伪装正常；已存在旧结果保留且清楚标记不是新 run。

## AUDIT-R1 输入输出/资格补充（F01–F04；覆盖上文较窄的分流措辞）

**输入确认门槛**：至少一份真实 CSV/XLSX 源文件；完整目标候选须目标模板（含字段顺序）或用户明确字段说明/有序规则及无争用的字段对应。规则明确标注每字段目标名、来源及确认态、required、类型/长度/允许值/日期格式、唯一组、参考文件与键及授权转换；未知属性以 UNKNOWN 表示，不填 `false`/`0`。声明参考核验时必须有可唯一解析的本次 CSV/XLSX 参考快照才能确认成员；缺失/键重复记录具体受影响行与规则。转换授权、生成全量副本授权、`--split` 授权互不推定；仅报告时无候选/隔离。输入原 CSV 文本字面值及 XLSX 单元格原类型/坐标不可变。

**确定性流水线**：选择源区域→确认一对一映射和目标字段顺序→保留原值检查快照→按限定范围授权转换→在最终候选值上执行每项适用已确认规则（required/type/min/max/allowed/reference/明确日期格式/最终唯一键）→按最终证据分类/分流→输出真实文件并重新打开核对。已解决原值问题写变更/前后差异（若展示历史 finding 则必须标 `RESOLVED` 并**排除**当前 finding 总数、受影响行数与隔离原因）；新增最终问题在问题明细及本次总数各计一次。每行每规则可通过、违反、未验证；多种不同规则同一行分别出 finding。未验证不等于违反，`无阻断记录数` 仍是旧概览字段，但必须额外提供可定位的 `已验证合格记录数`/`待确认记录数`（概览中独立项目或等价结构），让三态总数可重建，不能把无阻断计数称合格。

**实际文件**：`{原文件主题}-导入预检.xlsx` 的原五表保持；字段映射表明确目标字段顺序/依据（可增加列或概览项目），问题明细区分最终当前问题和已解决历史问题，变更记录带原/最终值及授权，未检查项带规则/原因/影响行/所缺资料；对于纯未检查无违规，问题数可为 0 但待确认数须非 0。明确授权目标数据时 `{原文件主题}-候选导入.xlsx`（或对应 CSV）的 `候选数据` 只有模板/有序规则的目标业务列，且无 `row_id/source_line`（除非目标模板明确要求）；审计 ID 存原报告/独立追踪映射，便于与候选行逐一关联。XLSX 编码文本读回为字符串 `00123`、`00008`（包括较长文本编号），不能为了表头/类型转换成数字；隔离文件 `{原文件主题}-隔离记录.xlsx` 可有 `row_id/source_line/原因/状态`，这些是审计列而非目标业务列。

**输出方式严格区别**：未授权时只有报告。仅授权全量转换副本时可有全部行，但副本应有不改变目标业务列的伴随元数据/独立追踪清单，且伴随报告明确 `待复核/非合格部分`、逐行注明已确认违规或未验证的资格限制，不得称全部可直接导入。授权 `--split` 时：只把*全部已声明适用规则已核验且无最终违规*的行放合格部分；有最终违规行、影响资格的未验证行放隔离，并分别注明 `VIOLATION`、`PENDING_VERIFICATION`（兼有时双列或多原因保留，不准压成一个伪违规）。若目标映射全局歧义无法定义目标表头，则不输出标成合格的目标候选；可报告/隔离或 NEEDS_INPUT，**不能**导出原列冒充目标表。非业务文件状态 `PARTIAL`（声明规则未验证而报告已生成）、`NEEDS_INPUT`（必要映射/区域不明且无法合法分流）、`COMPLETED`（本次可执行检查已完成，业务是否违规另判）、`REJECTED`/`FAILED` 沿用上文，不能将 PARTIAL + 空 findings 解读为合格。

**数量恒等式**：以稳定原业务 `row_id` 集合 S 为基准；split 时候选 C 与隔离 Q 满足 `C∩Q=∅`、`C∪Q=S`、`|C|+|Q|=|S|=输入记录数`，报告的合格/违规/待确认人数与逐行状态一致；混合违规与未验证者计一次业务行、分别记原因，不得漏/重/把一个重复组误当一条受影响行。全量副本仅复制 S 一次，不把它与 split 的候选加总。原件哈希前后相同，输出可重新打开；不安全文件/路径/公式文本保持原有安全约束。

**包与执行证据**：新版不可覆盖旧 0.1.4 ZIP。README、SKILL YAML version、ZIP 名、manifest/catalog candidate 与包外清单统一新版本；包内脚本/`references/rules.md` 实际存在，清洁解压后命令可直接执行；Python/第三方依赖的版本区间、隔离安装和许可核验状态可查。新版本及文件路径/哈希/成员清单/命令/退出码待授权开发和独立 QA 实测后填入证据，不在本合同猜测。
