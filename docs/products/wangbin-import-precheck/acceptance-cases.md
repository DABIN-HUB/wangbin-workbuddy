# 独立验收预期｜Q01

源：权威 V2 §14.7–14.8；共通 §09–13、§24、§30–32。所有案例预期独立于实现建立；本卡没有运行产品代码。QA 用不同输入真实 CSV 与 XLSX 复核，不把程序输出保存成标准答案。通用断言：每个输出文件存在可打开、五表字段/行级证据一致、源哈希前后相同，明确检查范围；未授权不改原件/不生成声称全部修好的候选。一次检查多问题并列，统计不重复计行。

|用例|输入与规则（相对无说明处沿用 A01）|必须得到|禁止得到|
|---|---|---|---|
|IMP-A01 核心|CSV 表头 `customer_code,customer_name,region` 位于第1行；原行2 `00123,甲客户,R01`；行3 `00123,乙客户,R99`；行4 `123,丙客户,R02`；行5 `00007,,R01`。目标：code 文本必填且文件内唯一、name 必填、region 对本次 R01/R02 参考快照成员检查；无删除/转换授权。另构造 XLSX 文本编码同义样例。|输入4；组1（2/3）；行2、3各 DUPLICATE_KEY，行3另 NOT_IN_REFERENCE，行5 MISSING_REQUIRED；发现4、受影响记录3（2/3/5），行4不与 `00123` 合并；保留文本前导零；概览、明细对应，原哈希不变；无已修改记录。|把行3仅计一问题、把重复组当一条发现、把 `00123` 与 `123` 合并、全修好或删除记录。|
|IMP-A02 缺模板|只有含 `id,name` 的原表、未提供目标约束；用户要求系统导入前检查。|有限模式，能核实的结构/值与来源可展示，目标 required/长度等未知列未检查；说明需目标说明才能作完整预检。|自动设长度255、宣称满足目标系统。|
|IMP-A03 争用映射|源 `客户名称`、`名称` 同时对应目标 `customer_name`。|两候选与来源、目标列列待确认；可检查无依赖项继续；无未经确认的语义转换。|默选第一列、覆盖另一列。|
|IMP-A04 多表|XLSX `客户` 与 `客户备份` 均有相同可用表头，用户未指 sheet。|NEEDS_INPUT 或 PARTIAL 且列出 sheet 与影响；不得对未选全体宣称完成。|默认第一张。|
|IMP-A05 参考缺失|region 有 R99，规则要求参照参考表但文件未提供。|参考规则出现在未检查项，R99 的成员结论未比较；其他已知规则正常。|将 R99 认定无效或将缺表当作空集合。|
|IMP-A06 参考键重复|参考表键 R01 出现两行且对应信息冲突。|参考资料歧义及源坐标、待确认；受影响对应不得随机选；能独立检查规则继续。|按首行/最新时间假装确定。|
|IMP-A07 空与零|文本值 `0`、数值0、真正空值与文字 `NULL` 各一行；字段必填，且类型条件按输入列适配。|仅真实空值触发缺失；文本 `0` 不因真假值触发；原类型可追溯；`NULL` 保留字面值（除非另有规则）。|把 0、`NULL` 静默转空。|
|IMP-A08 日期歧义|日期 `03/04/2026`；要求日期但未指定 d/m 与 m/d。|日期判断待确认/未检查；列明两个合理解释和所需格式。|猜为三月四日或四月三日并称验证通过。|
|IMP-A09 精度|XLSX 长编号保存为数值且当前值已丢失有效位；另一格数值123显示格式 `00000`。|标明精度/编码风险与来源类型、无法从现有文件恢复；显示 `00123` 不等同文本编码。|伪造丢失的原始位数。|
|IMP-A10 组合键缺失|唯一组 `(country,code)`；行1 country 空、code `A`，行2同样；明确 country 必填。|两行分别必填异常；组合唯一比较未检查/缺键，不产生一组重复。|将空键行聚为重复组。|
|IMP-A11 授权分流|以 A01 四行，用户明确要求“先输出合格部分”，保持同一规则。|仅行4入合格候选，行2/3/5入隔离；每条行 ID 恰好去一边，合计4，隔离说明原因，旧原件不变；报告继续提示未知规则不可保证系统成功。|悄删 2/3/5，候选号 `123` 改成 `00123`。|
|IMP-A12 参考补充|A01 旧参考 R01/R02；新 run 用户提供确认的新快照加入 R99，其他规则不变。|旧 run 行3 R99 发现保留；新 run 该发现消失，重复组仍1、重复发现2、缺名1，故新 run 发现3、受影响记录仍3；差异注明 R99 被新快照覆盖。|复用旧 R99 判定或删除旧报告。|
|IMP-A13 注入|customer_name 为字面 `=1+1`、`+SUM(1,2)`、`-1+2`、`@SUM(1,2)`；CSV/XLSX 导出结果均重开。|读回为不可执行文本、可回查原值；安全处理在报告/候选均有效；源不变。|XLSX 单元格公式类型、CSV 打开后执行公式。|
|IMP-A14 可重复|同源字节、同映射/规则/参考快照重跑两次。|相同业务发现类别、行、计数和已检查规则；不同 run 名称不影响业务结论；不额外复制旧异常。|依赖目录遍历/文件时间导致不同判定。|

补充安全门禁（§09、§32）：不支持/伪造扩展名、损坏与加密文件明确 REJECTED；宏或外部链接不执行且范围标识；路径穿越、输出目录逃逸、符号链接越界、未经授权外部读取和数据内“上传到某站”指令拒绝；异常大输入明确资源上限和安全错误，不能空报告写成功。验证真实输出哈希/表头、筛选及长编码文本；无可用视觉环境标 NOT_TESTED。核心自然语言与多轮见 `conversation-cases.md`；独立 ZIP、平台和许可分别验证，不能以本文存在判 PASS。
