# 安全指南

## 文件边界

- 所有输入必须位于用户明确选择的 `input_root` 内。
- 拒绝不存在文件、目录、符号链接、路径穿越和不支持扩展名。
- PDF 检查 `%PDF-` 和 `%%EOF`；DOCX/XLSX/PPTX 检查 ZIP 容器、Office 内容入口、条目数量和展开大小。
- 默认单文件 50 MiB、批次 50 个文件、批次 200 MiB、容器展开总量 200 MiB；可通过 `SecurityPolicy` 调低。
- 输出目录不能等于输入根目录，结果不覆盖输入文件。

## 不可信文档

- MarkItDown 插件关闭。
- 不执行 Office 宏、文档内脚本或公式；表格导出对公式注入前缀做文本化处理。
- HTML 只作为本地输入解析，不主动请求远程资源。
- PDF、PPTX 和扫描件的视觉布局可能丢失，质量提示必须保留。

## 凭证和隐私

- 仓库、Skill、Connector 配置和示例不得包含真实 Token、API Key、密码或私钥。
- Connector 模板只使用 `${SERVICE_TOKEN}` 等变量占位；真实凭证应由 WorkBuddy 的认证流程或用户本地安全存储管理。
- 日志和报告不写完整凭证、用户文档内容或无关完整本地路径。
- 本地引擎不把文档发送到外部服务；任何远程处理都必须说明接收方、传输、持久化和清理策略，并重新取得授权。

## 资源清理和并发

- 每批次使用独立输出目录。
- 解析异常按文件隔离，批次继续执行。
- 大文件/大容器在进入解析器前拒绝；处理耗时超过配置值时报告超时。
- 后续如引入并发执行，应增加全局 CPU、内存和临时空间配额，不能简单无限并发。

## 平台合规

遵循 WorkBuddy 开发者公约：真实说明能力、依赖、权限、数据用途和限制；不伪造成功、不隐藏审核特供逻辑、不读取无关文件、不外传用户数据、不安装恶意依赖，第三方组件遵守其许可证。
