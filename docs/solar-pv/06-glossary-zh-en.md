## 1. 首次出现与量纲规则

- 报告正文、图表标题/脚注和工作簿专业名词首次出现必须使用“中文全称（英文全称，缩写）”；无缩写则省略缩写项。后续可用缩写，出现歧义必须重申口径。
- 辐照度 Irradiance 是功率面密度，单位 W/m² 或 kW/m²；辐照量 Irradiation 是期间累计能量面密度，单位 kWh/m²。GHI、DNI、DHI 数据字段可能沿用缩写，必须读单位、期间和元数据后确定中文名称。
- POA 是组件平面参照；POA irradiance 与 POA irradiation 不混用。GTI 本文专指倾斜面累计辐照量；同一数据源另有定义时保留原字段但注明映射。
- kW/MW 是功率，kWh/MWh 是电量，MWp 与 MWac 保留不同物理侧标签；元/Wp 和元/kWp 换算必须按对应单位规则，不能只改单位文本。
- 财务 CF 指现金流，容量因子使用 CF_cap；同一上下文不得用无说明的 CF 混指两者。P/E 指项目/股权口径不是货币单位。
- 代码字段、JSON 键、状态枚举、来源标签及 formula_id/test_id 是机器标识，不冒称英文专业名词；状态枚举的中文解释见第 3 节。公式英文全称也逐一登记，避免报告首次使用遗漏。

## 2. 术语条目

### TERM-GHI · 水平面总辐照度

- 首次出现：**水平面总辐照度（Global Horizontal Irradiance，GHI）**。
- 定义：水平面收到的太阳总辐射功率密度，含直射投影和天空散射。
- 单位/维度：W/m² 或规范为 kW/m²。
- 区分与边界：GHI 缩写在数据集中可能表示累计量，必须读字段元数据；瞬时/平均辐照度不能直接当年辐照量。
- 公式：概念/资料项；本阶段无独立计算节点，不据此宣称已实现。
- 来源：USER-BASELINE §6 术语清单及项目方法定义；状态：方法定义、待适用标准或数据集定义复核。

### TERM-GHI-IRRADIATION · 水平面总辐照量

- 首次出现：**水平面总辐照量（Global Horizontal Irradiation，GHI）**。
- 定义：水平面总辐照度在指定期间的积分；与辐照度共享缩写时须加期间和单位。
- 单位/维度：kWh/m²/指定期间。
- 区分与边界：必须同时写期间；不是 kW/m²，不直接当阵列面 POA。
- 公式：概念/资料项；本阶段无独立计算节点，不据此宣称已实现。
- 来源：USER-BASELINE §6 术语清单及项目方法定义；状态：方法定义、待适用标准或数据集定义复核。

### TERM-DNI · 直接法向辐照度

- 首次出现：**直接法向辐照度（Direct Normal Irradiance，DNI）**。
- 定义：始终与太阳直射方向垂直平面上的直射太阳辐射功率密度。
- 单位/维度：W/m² 或 kW/m²。
- 区分与边界：不是水平面直射分量，也不是累计量。
- 公式：概念/资料项；本阶段无独立计算节点，不据此宣称已实现。

- 单位/维度：kWh/m²/指定期间。

- 首次出现：**倾斜面总辐照量（Global Tilted Irradiation，GTI）**。
- 定义：特定倾角和方位角表面的总辐照累计量；地面反射、遮挡边界依数据定义。

- 首次出现：**单位装机光伏发电量（Specific PV Power Output，PVOUT）**。
- 定义：数据源按其设备、损失和气象模型给定的单位装机发电量。
- 单位/维度：常见 kWh/kWp/指定期间，实际以源定义为准。
- 区分与边界：不得把 PVOUT 当 GHI 或 POA；模型已扣损失时不能再乘 PR。

### TERM-PR · 性能比

- 首次出现：**性能比（Performance Ratio，PR）**。

- 首次出现：**标准测试条件（Standard Test Conditions，STC）**。

- 单位/维度：条件集合。

## 3. 状态枚举与非数值输出

| 标识 | 中文含义/使用约束 |
|---|---|
| `PLANNED` | 规格已规划但未实施验证，不能写成通过 |
| `NOT_IMPLEMENTED` | 引擎/功能未实现 |
| `UNKNOWN` | 无足够资料，不能补成零 |
| `PENDING_VERIFICATION` | 有线索但须核实 |
| `ASSUMED` / `ASSUMPTION` | 可编辑情景假设，不是真实实测 |
| `CONFLICT` | 来源或口径冲突，依赖结论暂停 |
| `VERIFIED` | 仅有指定来源/审核证据的字段才可用，不表示整个模型通过 |
| `UNVERIFIED` | 输入尚未得到有效核验 |
| `NOT_APPLICABLE` | 有理由不适用，不是缺资料 |
| `NO_SIGN_CHANGE` | IRR 现金流无正负变化，不返回伪造收益率 |
| `NO_ROOT` | 声明域和方法范围内未找到/证明无有效实根，须说明证明完备性 |
| `MULTIPLE_ROOTS` | 存在多个有效实根，保留根集，不任挑有利值 |
| `INDETERMINATE` | 例如全零现金流导致任意率均满足，不能定义唯一 IRR |
| `NOT_CONVERGED` | 数值求解未收敛，不等于无根 |
| `ROOT_ENUMERATION_INCOMPLETE` | 未证明根搜索穷尽，不冒称全域唯一 |
| `NOT_RECOVERED_WITHIN_HORIZON` | 期内未回收，不报虚构年数 |
| `ZERO_DEBT_SERVICE` | 有债务但本期服务分母零，不给无限 DSCR |
| `ZERO_DELIVERY` | 可利用交付电量折现分母零，LCOE 不可计算 |
| `UNDEFINED` | 比率或数学条件不满足，返回类型化非数值原因 |
| `ADDITIONAL_EQUITY_REQUIRED` | 出现资金缺口，需新增资本金/资金计划，不藏负现金 |
