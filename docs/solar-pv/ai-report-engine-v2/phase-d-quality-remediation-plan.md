1. 事实槽直接拼接原unit，`currency`没有读者精度政策；无量纲比例缺指标语义，IRR将整段技术说明拼入正文。属于生产展示链问题，不是抽取误差。
2. 结算适配器只提供月度细目，年度ledger及已计算自用比例没有进入小节；金融台账未供CH16.01读取。需补只读投影，不新增公式或报告层求和。
3. 旧机械封装脚本把所有formula_refs设为空；局部Word已有OMML装配入口，并非只能等Phase F。本轮复用该入口，增加符号解释及按选中ID转换，未重新设计89公式。
4. 同canonical的地面`settlement.price_source`须追踪真实市场时序，不能把示例tariff.periods当作收入所用电价。
5. 当前保留基准canonical的3D未携带独立transaction_cost_cash_paid字段；不得把缺值填零，也不能把上一轮候选费修复移植为基准已重算证明。基准NPV/IRR照原值展示，但明确费用现金绑定待核对，不能将它们认定为全面闭环的投资结论。
