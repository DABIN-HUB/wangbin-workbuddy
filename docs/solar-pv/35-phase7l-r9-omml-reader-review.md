# Phase 7L-R9：Word 数学对象与读者分层审阅（非发布）

## 不可变边界与实际实现

本轮只改长期报告生成器及相应回归；冻结的469输入字段、89个正式公式定义、281条映射、189条术语、18章/100正文子项、13附录/26子项和既有计算引擎未改。两案 canonical `result_hash` 分别为屋顶 `ca4bdff3f5e89e6770d43f4dad3b4efd57d965aba6c9ba0f1b4299f99295a43f`、地面 `69882cc39020f03fb3ef6cdb1a10b188c324de0f66066392970776b7495ad138`。案例和合成假设不构成现场资料或投资批准。

`report_equations.py` 按正式 ID 从冻结注册表获取89个定义，先将每条 LaTeX 转成 Pandoc 的 DOCX OMML，再插入居中的 Word 数学段落，右侧使用独立编号单元格（1）至（89）；转换器不可用、报告条数或数学对象不匹配即报错，不回退普通文本或图片。40条显示专用的逐 ID 记法用于修复多字符上下标、求和/连乘运算项、分式及存储变量；**保留原始 `latex`、`text_equation`、符号和量纲不变**，在公式下展示冻结文字定义。不能对显示记法成功解析就推定其与所有冻结文本含义一致。

`F-UNIT-COST-WP-KWP` 存在独立源内冲突：原 `latex` 将 `c_Wps` 连写，正式 `text_equation` 则是 `c_kWp = c_Wp × s`。显示层按后者显示明确乘号，原两式并列保留；待方法负责人核定原注册表前，`FORMULA_MATH_SEMANTICS=PARTIAL`。不得悄悄用显示映射改写源公式或宣称89式语义全通过。WPS 保存也会将四式的数学字形标记规范化（星号、集合花体等），需分别审查 XML 结构与 PDF 实际字形。

生成器的读者层：附录 K 先列用途/适用边界/89个 F-ID 索引，再保留完整技术定义和逐式符号；附录 L 先列各案24条**有释义及适用说明**的常用术语，再保留189条完整受控词典与单位边界，表118与表119标题区分。全量技术资料并未裁删，篇幅依旧较长，不能将“读者速览”解释成压缩了正式附录。

正文摘要/决策指标按单位显示：金额与电量取整数、IRR百分比与回收年数保留两位；月度和审计明细的精度不依此丢弃。CH14.02 设备单价保留源值精度、数量与计价单位取逐项冻结来源；源字段 `unit` 仅译为通用“件”，未绑定单位不猜测为“块/台/项”；分项金额若取整则并列展示源值，不再拼出错误的“取整单价×数量＝取整金额”。常用术语及附录公式阅读导航的 NPV/IRR/LCOE 等适用说明按当前指标状态区分，债务与 DSCR 按来源核实后的债务比例和指标状态区分；这些状态提示不提供实测项目审批结论。所有显示均从同一个 canonical 读取，HALF_UP 仅作用在字符串，现金流/NPV/IRR等源数未重算。已存在的财务时点、合成来源、交易费预计付款与真实付款的边界维持原有阻断。

### 本地可复现条件

运行环境须提供**独立安装的** Pandoc 可执行文件，例如设置环境变量 `WANGBIN_SOLAR_PV_PANDOC` 为完整的 `pandoc.exe` 路径；也可将 `pandoc` 放入 `PATH`。此项是报告导出依赖而非LLM/密钥，不将下载的可执行文件、商业再分发许可证或本机 scratch 路径打包进 Skill。未安装时 `REPORT_OMML_CONVERTER_UNAVAILABLE` 失败，不应把这种环境阻断伪装为报告生成通过。固定版本的包许可、跨环境安装与 WorkBuddy 运行需分别验证。
