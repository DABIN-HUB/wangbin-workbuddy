## 三、计算引擎的主要内容

### 3.1 装机容量与电气配置

实现冻结公式中属于本阶段的：

- 光伏组件数量与直流容量。
- 交流侧额定容量。
- DC/AC 容配比。
- 可用面积与装机规模关系。
- 阵列配置。
- 单位装机功率指标。
- 相关工程参数一致性校验。

必须区分：

- W：瓦，功率单位。
- Wp：Watt-peak，标准测试条件下的光伏峰值功率。
- kWp：千瓦峰值。
- MWp：兆瓦峰值。
- DC：Direct Current，直流。
- AC：Alternating Current，交流。

不能将 MWp 直接等同于 MWac。

当面积、组件尺寸、间距或其他关键参数不满足所选模型要求时，必须明确返回缺失或不可计算状态。

不能使用固定的“每平方米装机功率”代替所有项目的工程计算。

### 3.2 太阳能资源和辐照量处理

支持输入经过 Phase 2 校验的：

- GHI：Global Horizontal Irradiance，水平面总辐照度或相应累计辐照量，必须按实际单位区分。
- DNI：Direct Normal Irradiance，直接法向辐照度。
- DHI：Diffuse Horizontal Irradiance，水平面散射辐照度。
- POA：Plane of Array，组件阵列平面。
- GTI：Global Tilted Irradiation，倾斜平面总辐照量。
- 环境温度。
- 风速。
- 组件倾角和方位角。
- 项目坐标与时间信息。

必须区分辐照度 W/m² 与累计辐照量 kWh/m²。

如果数据已经是组件平面辐照量，不得再次执行相同的转置计算。

如果只有 GHI，不能在缺少其他所需数据或经验证的方法配置时，直接将 GHI 认作 POA。

Phase 4 才正式接入真实气象服务。本轮使用带明确来源和状态的合成数据进行数值测试。

### 3.3 组件温度与温度损耗

按照已批准的 D2 方法配置实现温度子模型。

要求：

1. 使用明确的方法类型和版本。
2. 使用明确的组件及安装参数。
3. 正确计算环境温度、组件温度与电池温度的关系。
4. 正确应用温度系数。
5. 严格控制输入和输出单位。
6. 保留方法选择、参数、来源和公式血缘。
7. 不得默认组件温度等于环境温度。
8. 不得偷偷采用一个无来源的固定温度损失率。

对于没有足够参数的输入，返回明确缺口。

对极端低温、高温、零辐照及不合理参数设置专项测试。

### 3.4 发电量计算

实现所选模型对应的：

- 时间区间发电量。
- 月度发电量。
- 年度发电量。
- 首年发电量。
- 单位装机发电量。
- 等效利用小时数。
- 性能比 PR。
- 逆变器交流输出电量。
- 限制条件下的可交付电量。
- 全生命周期发电量。

PR 必须解释为 Performance Ratio，即性能比，并明确分子、分母和计量边界。

不同模型的发电量边界必须清楚。

如果使用已有综合损失后的发电数据，不得再重复扣除同一损失。

输出不能仅有年度一个数字，必须包含足够的中间结果及公式血缘，供后续消纳模型和报告使用。

### 3.5 系统损失模型

按照已批准的受控损失顺序实现：

- 温度损耗。
- 遮挡损耗。
- 组件失配。
- 积灰及适用的积雪损耗。
- DC 线路损耗。
- 逆变器转换损耗。
- AC 线路损耗。
- 变压器及送出损耗。
- 设备停机与可利用率。
- 逆变器限幅。
- 限发与弃光。

按冻结注册表及适用的专业方法区分各项损失。

不同损失可能属于直流侧、交流侧、电网交付侧，不能无条件相加或者重复扣除。

逆变器削峰应在有足够时间分辨率和设备参数时计算，不能从单一年度总辐照量伪造准确削峰损失。

如输入数据不足，应返回明确的受限测算状态。

### 3.6 组件衰减及设备更换

实现：

- 首年初始衰减。
- 后续年度性能衰减。
- 逐年发电量变化。
- 分段衰减。
- 组件或设备更换后的适用性能变化。
- 全生命周期累计发电量。

必须处理首年衰减与逐年衰减重复计算的问题。

设备更换后的恢复量不能凭空设置，需要明确参数及方法依据。

对于存在逆变器限幅和负荷匹配的模型，不允许未经验证便直接按年度比例缩放所有交付电量，并宣称获得了精确的各年运行结果。
