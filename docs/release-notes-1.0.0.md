# 1.0.0 版本更新日志

- 建立 wangbin WorkBuddy 独立工程结构。
- 核实官方 Skill、Expert、Connector、个人认证、开发者公约和变现文档。
- 基于 MarkItDown 0.1.9 实现 PDF、DOCX、XLSX、PPTX、HTML、TXT、Markdown 的真实读取。
- 实现批处理、失败隔离、Excel 去重和 CSV/XLSX 安全导出。
- 增加路径、符号链接、扩展名、Office 容器、文件大小、批次大小和公式注入防护。
- 增加 WorkBuddy Skill、Expert、MCP Connector、CLI Connector 模板。
- 增加 `validate`、`test`、`package`、`release-check` 统一命令。
- 生成真实文档夹具、测试证据和本地发布候选 ZIP。

## 未包含

本版本不包含模型远程调用、真实企业连接器、WorkBuddy 登录/上传/审核、收费或生产部署。
