## 根集证明边界（问题 4–5、8–10）

**已经证明的正式可执行模型范围：无。** `CERTIFIED_MONOTONE_RECALCULATION` 是 D2 配置名称而非证书；现有 `precision.abs_tolerance` 是通用按指标解释的校验容差，未批准为独立的**元** NPV 根残差容差。当前有限精度 Decimal 回放对任意实数价格域既未证明全域连续，也未证明严格单调；极近但不同的候选售价可得到相同的舍入收入。税费、收款、负价、结算上限及跨期状态也未取得适用于所有项目／分支的穷尽证明。即使有端点变号或少量正 NPV 点，也不能将样本插值或数值扫描提升为完整根集合。

独立一期模型的**理想有理算术**可在 `[0,2]` 元/kWh 的事前声明范围内推导：售电量 87600 kWh，收款比例 0.75，含税 OPEX 180000 元。VAT 最大销项 `2277600/113` 小于进项 `2354690/113`；项目所得税基最大 `1684600/113` 小于事前期初亏损 34000 元。因此理想模型 VAT 与所得税现金均为零，`NPV(p)=-1330+(65700p+140160-180000+200)/1.1`，端点为 `-411030/11` 与 `902970/11` 元，唯一理想根为 `4567/7300` 元/kWh。**这些是不依赖生产求根器返回值的数学参考，仍不能证明有限精度正式根集。**

本轮真实全链回放得到 `NPV(0)=-37366.363636363636... 元`、`NPV(2)=82088.181818181818... 元`，以及在 100 位 Decimal 表示的 `4567/7300≈0.625616438356... 元/kWh` 处 `NPV=0E-22 元`；候选价格与无限精度有理参考的精确差严格 `<1e-100 元/kWh`，候选**实际货币残差**为 0 元。候选现金流仍经过完整 3C、3D、3E，观察到 VAT 留抵、所得税现金为零。但该单点的零值既非根集合证书，也不等于求根**隔离区间宽度**：未执行正式收敛搜索，区间宽度与获批准的货币残差门禁均记为未取得，不得填零。完整数值精度见机器证据的原始 Decimal 字符串及真实结果哈希。

形式化入口仅接受真实会话；输出沿用 canonical result、`seal_result()`、`validate_result()` 和既有 `BLOCKED_MISSING_INPUT` 状态，证据列出具体未满足义务并绑定原始 3B／3C／3D／3E、D3、终期字节、公式版本与执行源码 SHA。无正式根、`NO_ROOT`、多根或零平台结论。税费在每个实际候选中由既有 3D 重算；VAT 留抵及所得税分支是明确验证项，未将未知现金当零。该参考候选售价不能替代全域证书和获批准的双残差门禁。

## 接口、状态和保护（问题 6–7、11–15）

本轮根项目 L1：**4 passed**，包含真实有根参考点／两端、同源原价、旧插值隔离、缓存篡改阻断；正式阻断专项复跑 **1 passed**。关联 L2 **59 passed、1 skipped**（Windows 无 symlink 权限；60 项，实际 `15332.98s`）。本轮最终代码光伏 L3 **4177 passed、7 skipped**（`20772.34s`），WorkBuddy/Expert L3 **109 passed、5 skipped**（`56.57s`）；全部完整 JUnit、分组测试 ID 与原始结果归档于证据目录。各分组存在重叠，不累加为虚假的全套通过数。保护基线重新实测 **286 匹配、2 个预存差异、0 缺失**；六份既有用户差异文件的原始 SHA-256 保持不变。证据文件凭据赋值及 URL 用户信息扫描未发现命中；冻结公式目录的 `token` 字段仅表示公式语法。性能及受控项目代码分别本地提交 `02887ce`、`d07e487`，不 push。若价格域完整证明、元单位残差容差和预算无法同时满足，本阶段按停止条件保持正式求根 BLOCKED，只保留经验证的性能和受控候选成果，不进入 P2-5／3F／4，不部署／发布。

## 十五项审查答复

1. **原价重复成本降低：是。** 两候选会话原价 3C／3D／3E 仅各生产一次；后续候选不再重算原价，独立 3D 终期账簿复核仍保持。
2. **单候选耗时／次数：** 原始 842.339448 秒且原价／候选各一套；会话首开连首个候选 949.757094 秒，后续候选 576.059817 秒且只生产候选一套。两次候选的总效果、I/O 和内存见性能表。
3. **来源安全：** 同价原始／候选 `result_hash` 与 NPV 相同；原价 3B 原始文件、D3、终期字节、公开接口缓存边界和已发布原价 3C／3D／3E 文件均被重新核验；私有目录所有权与预算被保持。以上不宣称针对具有并发恶意写权限者的 OS 级隔离。
4. **取得严格正式根集证明的模型范围：无。** 只有固定一期假设下的理想有理算术单调证明，并非可执行 Decimal 全域证书。
5. **仍未证明：** 有限精度连续性／严格单调、全部可接受价格及税费／结算分支、已批准元单位 NPV 根残差，其他多年／封存／EVENTS 模型更不在证书内。
