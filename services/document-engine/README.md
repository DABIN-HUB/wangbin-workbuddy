# wangbin-document-cli

Python wheel containing the wangbin document engine and the local-only CLI. No remote account, service or runtime download is needed while processing a document. Installation downloads pinned direct Python dependencies from the configured Python index; obtain permission and verify the index before installing.

After installation: `wangbin-document-cli doctor`, `wangbin-document-cli status`, and `wangbin-document-cli parse --input "<file>" --input-root "<directory>"`. See repository `docs/phase2-runtime-install.md` for all commands and platform limitations.

This wheel is a local install artifact, not an already published package on PyPI or proof of WorkBuddy platform installation.
