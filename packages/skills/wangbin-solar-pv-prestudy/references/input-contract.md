# 光伏预可研输入契约摘要

此文件是 Skill 的用户沟通摘要，不替代仓库中的 Phase 2–4 冻结契约和计算引擎。

## 共同身份字段

- 项目 ID、项目名称、项目类型、评价日期、场景；
- 输入版本和来源快照；
- `model_version`、`run_id`、`input_hash`、`source_snapshot_id`、`result_hash`；
- 资料的来源、时间范围、地理范围、单位、授权和敏感等级。

## 工商业屋顶必查轴

| 证据轴 | 重点资料 | 缺失时的边界 |
|---|---|---|
| 屋顶边界 | 坐标/厂区边界、可利用面积、遮挡、屋顶权属或租赁期限 | 不生成屋顶可建设结论 |
| 结构安全 | 结构鉴定、允许附加荷载、加固、防水和消防边界 | 不生成承载或施工结论 |
| 负荷消纳 | 同粒度负荷曲线、计量点、时区、质量说明 | 不伪造自用率、可避免费用或合同节省 |
| 售电并网 | 电价合同、分成/PPA、接入点、容量、限发/交易约束 | 收入和并网保持 UNKNOWN/BLOCKED |
| 设备成本 | 型号参数、数量、报价时点、税和运输/施工边界 | 预算只能保留假设状态 |

## 集中式地面必查轴

| 证据轴 | 重点资料 | 缺失时的边界 |
|---|---|---|
| 土地合规 | 权属、用地性质、面积、期限、可建设范围、生态/林草/水保约束 | 不生成土地合规结论 |
| 地形地质 | 测量、坡度、地质、洪涝/灾害、桩基和基础条件 | 不生成地勘、基础或工程量结论 |
| 场区工程 | 总平面、道路、排水、运输、施工组织 | 保持专项工程 UNKNOWN |
| 电气送出 | 集电线路、升压站、送出工程、接入系统意见、调度 | 不生成并网容量或送出结论 |
| 市场收益 | 上网/交易合同、市场价格、限发、辅助服务口径 | 不把屋顶自用收益模型用于地面项目 |
| 投资运维 | 地面专项 CAPEX、OPEX、地租、替换、保险和融资依据 | 不由 CAPEX 总额推断现金流闭合 |

## 状态含义

- `EVIDENCED`：对应直接输入或已计算指标存在；不等于真实来源已正式验收。
- `UNKNOWN`：没有足够直接证据。
- `BLOCKED` / `PENDING_VERIFICATION`：上游来源、计算或专业审查阻断。
- `NOT_APPLICABLE`：该项目类型不适用，例如地面项目的屋顶自用负荷模型。
- `NOT_IMPLEMENTED`：引擎尚未实现该项。
- `NOT_TESTED`：本轮没有执行该验证。
