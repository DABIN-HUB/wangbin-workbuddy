# 隐私与安全说明

- 输入文件默认只读，且必须位于用户明确授权的输入根目录内。
- 不读取用户未选择的文件，不跟随符号链接，不允许路径穿越。
- 输出写入独立目录，不覆盖原文件；临时资源在任务结束时清理。
- Office 容器会限制条目数量和展开大小，避免 ZIP 炸弹；宏、脚本和危险公式不执行。
- CSV/XLSX 导出会把 `=`, `+`, `-`, `@` 开头的内容按文本处理，降低公式注入风险。
- 本地引擎不主动向外部服务发送文档。若将来接入远程服务，必须先说明接收方、传输方式、持久化和清理策略，并重新取得用户授权。
- 报告脱敏错误信息，不包含完整凭证、Token、密钥或无关本地路径。
- 用户应在分享结果前自行检查文档中的个人信息、商业秘密和受限内容。
