## 使用与限制

在当前会话基于用户授权的脱敏文字澄清需求、选型、设计、报价、交付文本和验收计划；没有客户生产数据库、支付、设备、后台或跨会话持久化。报价按受控范围/工作包及已批准的示意参数计算，外部未知费待询价，不冒充市场行情或正式合同。自然语言交互不要求用户填写 JSON/CLI。案例/测试留在源码目录且不入 ZIP；旧 1.0.0、1.1.0 是历史候选身份，不以旧 ZIP 代表当前 1.1.2。当前第三批只做源码和文档一致性，不生成、覆盖或声称验收当前候选包。以后如获授权构建，必须记录精确源 HEAD、ZIP 和逐成员哈希。非官方部署、审核、收费或发布回执均不得宣称已获得。

本包不运行独立后台、MCP、数据库或外部 API；若平台授权包内 Skill，则可进行有限确定性人工费核算。未获授权时仅对话输出文本。平台解析、召唤和模型表现未经 WorkBuddy 真实验证。

## 用户能得到什么

- 用最多三项优先问题逐轮澄清目标、角色、人数、流程、接口、迁移、部署、预算与周期；即使用户暂不回答，也先提供有用的初稿。
- 输出已确认需求、假设和待确认事项；将功能拆到输入/处理/输出/异常、优先级、依赖、验收标准。
- 结合规模比较单体与复杂系统架构，工业协议先确认现场设备能力和网络/许可边界。
- 完整报价按 `MVP=M`、`StandardA=M∪S`、`StandardB=M∪S∪I`、`FullA=M∪S∪F`、`FullB=M∪S∪F∪I` 五档独立成员计算；I 仅为两个 B 档的实际接口实施条件增量。A/B 只有范围、费用事实/计价口径与适用条件均有证据且相同才合并摘要，详细档位不合并；单项估算不强制五档。按实际参与的全部角色及唯一工作包列人天、缓冲、单价与外费；Decimal 只核验受支持的四角色低高及获许可的同价人工费等回执项目，不核整个报价。
- 按需在对话里输出需求说明书、模块清单、分终端页面导航、技术方案、数据库与 API 草案、WBS/个人或条件排期、预算参考、验收/上线计划等 Markdown 文本；不是已生成可下载附件。已证实的资产复用才入基础估算，待核则列可比较的条件差量。
