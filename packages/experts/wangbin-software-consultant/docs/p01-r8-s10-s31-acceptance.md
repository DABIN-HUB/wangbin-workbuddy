- S31 单轮旧→新及真两轮：当前消息中的改价是**本轮**发生，不得因写入当前状态后又称“本轮无新变更”。区分旧固定价 1000、新固定价 1200 元/人天；B=30/45、r=10%/20%、E=33/54 均不变；旧人工费 33000/54000、新人工费 39600/64800 元，外部费未知。固定价不得由默认参考区间覆盖，旧价金额不能作为新价金额。只改缓冲对照则价格不变、人天与费用随新缓冲重算，不能误写改价。负对照：R7 第二轮金额虽正确但否认本轮变更应判 FAIL。
- S12/S13/S29/S30 按原合同回归：S12 示意与已确认区分、拒价/默认许可；S13 最新范围去采购并重算；S29 当轮两个条件候选与各自损失及已知 40000 差额；S30 双接口分支、三档 B/E 和价态。任何算术或关键词检查不可取代完整业务判读；S17 外部费用仍未知。
