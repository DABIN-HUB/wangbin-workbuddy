## 1. 许可状态与计算层分离

| 当前会话最新有效用户状态（先处理撤销/冲突） | A：可核工作量 | B：开发人工费人民币 | 禁止/说明 |
|---|---|---|---|
| 固定人天单价 `p` | 各工作包角色人天→B→有根据的 E | `E_L×p..E_H×p` | 固定价覆盖参考价；变价不改人天 |
| 各角色单价 `p_role` | 按角色分别累计且同一缓冲口径 | 对各角色缓冲后人天分别乘自身价格再求和 | 不得用无来源平均价；缺少关键角色单价只列已知部分，余项变量待定，不伪报完整金额 |
| 明确允许已批准参考价 | 同上 | `E_L×1000..E_H×1500` 元，标示意 | 不虚构行情 |
| **没给价、没拒绝参考价（沉默）** | 同上 | **可默认**上述示意区间 | 沉默≠拒绝；这是 R5 替代 R4 的精确变更 |
| 明确拒绝参考价，且无另一个有效单价 | 同上 | **不计算人民币**；仅在需要时写 `E×p` 变量式 | 不将拒绝解释成拒绝人天 |
| 只要人天、明确不要人民币 | 同上 | **不计算人民币** | 优先尊重输出限制，即便先前给过单价，除非后续明确改变意图 |
| 可靠工作范围不足 | 仅可交付部分的工作包与缺口，无法推导部分不造 B/E | 未可计算部分不造人民币 | 初轮模糊 OA 不从未知员工/审批数硬凑有限估算；澄清后重新判定 |

**输出默认示意价时逐字注明**：“人民币 1000～1500 元/人天为用户批准的示意估算参数，并非实时市场行情或正式合同报价。” 该单价是用户批准的演示参数，不是可作为行情引用的外部证据；用户固定/角色价格需写明来自哪轮。含税/舍入/币种条件缺失须标待确认。外部第三方许可、云、设备、接口、硬件、单独部署及周期维护逐项区分，未知写待询价；不能以 0 计完整总价，已计入人工人天的部署不得重复计费。任何默认价都不能补出不存在的工作量或精确合同报价。

每工作包记录稳定 ID、最新有效需求/假设来源、交付物、角色 FE/BE/必要专项、各角色低高人天、任务依赖/验收；逐角色加至工作包、逐包加至 `B_L=ΣL_i, B_H=ΣH_i`，同包只计一次。只有缓冲率有用户确认或**清楚标注的示意假设及依据**才输出数值 `E_L=B_L×(1+r_L), E_H=B_H×(1+r_H)`；否则给 B 和条件公式，不伪造已确认的 E，更不能为求 C 私自设 r=0。可计算 E 后方计算 C。每人每天约五个细分功能点仅合理性校核；小型每实际参与者约 1、中型约 1.5、大型约 2～5 人天，超范围继续拆；FE 与 BE 分别计，后端独有时 FE 为不适用；复杂度法和五点法不叠加，已计入模块的测试/部署不重计。未知、不适用、零、否定、假设与事实不得混同。
