# wangbin Expert 模板

此模板严格采用 WorkBuddy Expert 官方结构：`.codebuddy-plugin/plugin.json`、`avatars/`、`agents/` 和 `README.md`。本地校验器会检查必填字段、Agent 路径、固定 3 个标签和固定 3 个快捷提示。

本阶段不提交平台审核，不声明已通过 WorkBuddy 专家运行时验证。

开发或修改 Expert 时，先读仓库根目录 `AGENTS.md`，再完整读取 `agent.md` 和本产品专属冻结合同；执行 `docs/development-task-template.md` 中的测试、清理、dist 保护、显式暂存、本地提交及最终 Git 状态检查。本段只约束仓库开发，不会被平台自动注入 Expert 运行时；禁止自动 push 或发布。
